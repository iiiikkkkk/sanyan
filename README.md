# sanyan
## 正文影印

正文影印 PDF 按篇目和刊本存放在 `pdf/`。[图文阅读页](read.html)提供三书篇目目录、影印插图浏览、插图与电子正文或原书影印对读，以及正文影印的翻页、页码跳转和缩放。有多个刊本的篇目可切换刊本或双栏对照。每份文件的扫描页序、馆藏、索书号、数字来源和使用说明见 [facsimiles.json](facsimiles.json)。扫描页序从原文件第一页起算，起止页均包含。个别边界图像裁去同张照片上的相邻篇半叶。

刊载的 PDF 来源为 Wikimedia Commons 标示公有领域的扫描。早稻田大学藏本、东京大学东洋文化研究所的两种影印和上海图书馆藏大字本《今古奇观》留作研究资料。站内阅读器使用随站发布的 PDF.js，许可证见 [vendor/pdfjs/LICENSE](vendor/pdfjs/LICENSE)。
